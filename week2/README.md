# Week 2 - Perceptrón

##  Objetivo
Implementar una red neuronal básica (perceptrón) en Python para comprender cómo las entradas, los pesos y el bias determinan la salida de clasificación binaria (0/1).

##  Qué se implementó
- Una función perceptron que calcula el puntaje z y aplica una función de activación binaria.
- Un conjunto de 10 casos de prueba controlados, variando pesos y bias.
- Evidencia visible de resultados en tablas impresas para cada prueba.
- Análisis escrito en Markdown con conclusiones breves sobre el efecto de los parámetros.

##  Pruebas realizadas
Se definieron 10 pruebas con distintos parámetros:
1. Variación de pesos.  
2. Variación del bias.  
3. Compuerta OR.  
4. Bias más negativo.  
5. Pesos distintos, bias neutro.  
6. Pesos altos, bias fuerte negativo.  
7. Compuerta AND clásica.  
8. Compuerta NAND.  
9. Compuerta NOR.  
10. Compuerta NOT (una entrada).  

Cada prueba muestra cómo cambian las decisiones del perceptrón según los valores de pesos y bias.

##  Resultados principales
El perceptrón puede simular compuertas lógicas básicas (AND, OR, NAND, NOR, NOT) y demuestra que los pesos controlan la influencia de cada entrada, mientras que el bias ajusta el umbral de activación.

2. Ejecutar todas las celdas en orden.  
3. Observar las tablas impresas con los resultados de cada prueba.
